# Project provenance

GroundSignal began as a partially built weather-oracle hackathon prototype. The
v1 work keeps that Git history intact while replacing the prototype product,
runtime boundaries, storage model, and claims with a reusable open-source
reference implementation.

Weather remains the sole adapter because it makes the protocol concrete: a
model forecast can be compared with a deterministic set of human-witness
reports. The public demo does not represent a live network, real observers,
earnings, or settled payments.

Historical code remains available in Git. Stale planning files and framework
starter assets were removed from the v1 tree so contributors have one current
source of truth: the README and the documents in this directory.
