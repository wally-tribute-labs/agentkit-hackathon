# Security policy

## Supported version

Security fixes are applied to the latest `1.x` release and the default branch.

## Reporting

Please use GitHub private vulnerability reporting when it is enabled. Otherwise, contact the repository owner privately rather than opening a public issue. Include impact, reproduction steps, and a minimal proof of concept without real credentials or personal location data.

Do not test against accounts, wallets, World ID proofs, or infrastructure you do not own. No bounty is currently offered.

## Scope and guarantees

The public demo is simulated. SQLite mode is intended for a single writable instance. Optional testnet integrations are experimental and must not be used with mainnet funds. See [the threat model](docs/THREAT_MODEL.md).
