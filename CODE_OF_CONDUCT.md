# Code of Conduct

We are committed to a respectful, harassment-free community for everyone. Be considerate, welcome constructive disagreement, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discriminatory language, threats, publishing private information, or sustained disruption. Maintainers may remove contributions or restrict participation when behavior undermines a safe, productive community.

Report conduct concerns privately using the contact method in the repository security policy. Maintainers will review reports promptly, protect confidentiality where possible, and respond proportionately.
